# Shared-group-expense-splitting-system
This project is a Java Swing desktop application integrated with Firebase Firestore designed for transparent group expense management. It features a secure Admin Control Panel for approving new members, adding bills, and settling debts, while automatically calculating individual "shares" by dividing total costs among approved users. The interface utilizes a clean, color-coded "flat-box" design to distinguish between urgent unpaid expenses and historical records, ensuring all group financial activity is tracked in real-time.
